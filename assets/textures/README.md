# Scanned textures

From [Poly Haven](https://polyhaven.com), CC0. Each folder is one asset: `diff` (albedo),
`nor_gl` (OpenGL-convention normal) and `arm` (AO / roughness / metal packed in R / G / B, read a
channel at a time by `Materials.scanned`).

- `herringbone_parquet` — the floor
- `black_walnut_veneer_01` — the console's end cheeks
- `wool_boucle` — the rug
- `rough_linen` — acoustic panel cloth

Fetched with `https://dl.polyhaven.org/file/ph-assets/Textures/jpg/<res>/<id>/<id>_<map>_<res>.jpg`.
